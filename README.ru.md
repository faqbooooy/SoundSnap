# SoundSnap

[English](README.md) · **Русский**

<img src="src/soundsnap.png" alt="Логотип SoundSnap" width="48" height="48">

SoundSnap — небольшая утилита для Windows, которая переключает звук между колонками, наушниками и другими выходами одним кликом по значку в трее или горячей клавишей. Например, можно оставить в быстром переключении только колонки и гарнитуру, сохранив доступ ко всем остальным выходам из панели.

## Скачать

Скачайте **SoundSnap.exe** из раздела [Releases](https://github.com/faqbooooy/SoundSnap/releases/latest) и запустите его. Сборка предназначена для Windows x64 и не требует установки. Если значок не виден, откройте список скрытых значков Windows.

## Управление

| Действие | Результат |
| --- | --- |
| Левый клик по значку | Переключить звук на следующий выход из быстрого списка |
| `Ctrl + Alt + F9` | Переключить звук с клавиатуры. Сочетание можно изменить в настройках |
| Наведение на значок и прокрутка | Показать полоску громкости и изменить уровень колёсиком |
| Средняя кнопка мыши по значку | Выключить или вернуть звук на текущем выходе |
| Правый клик → **Открыть** | Показать панель с устройствами и громкостью |

На главной панели видны активный выход и следующий в цикле. **Все устройства** раскрывает полный список для ручного выбора. В **Настроить список** отметьте галочками выходы для быстрого переключения. Изменения сохраняются сразу.

SoundSnap запоминает громкость отдельно для каждого выхода. При переключении через приложение сохранённый уровень выставляется на целевом устройстве до перенаправления звука. Если выставить сохранённый уровень не удалось, SoundSnap оставит текущий выход.

## Микшер и профили звука

Откройте **Микшер** с главной панели или из меню значка в трее, чтобы изменить громкость отдельных аудиосессий. По умолчанию микшер следует за выходом Windows. Нажмите **Аудиовыход**, чтобы увидеть сессии другого подключённого устройства. У одного приложения, например Discord, может быть несколько сессий со своими ползунками.

Выберите **Профили → Создать профиль**, чтобы взять текущие настройки звука за основу. Дайте профилю имя, отметьте нужные приложения и настройте их громкость или отключение звука. У каждого профиля может быть своя горячая клавиша, запасной выход с отдельной громкостью или режим «Без звука» на случай отключения основного выхода. Возврат звука на основной выход при переподключении можно включить или выключить.

Профиль хранит одну настройку на приложение и применяет её ко всем его аудиосессиям.

## Настройки и обновление

По умолчанию SoundSnap следует языку интерфейса Windows: русский интерфейс при русском языке системы, английский — при любом другом. Язык можно вручную переключить кнопками **RUS** и **ENG** в шапке настроек. Изменение применяется сразу.

В настройках доступны светлая, тёмная и системная темы, горячая клавиша и автозапуск. Настройки и профили хранятся в файлах `settings.json` и `profiles.dat` внутри `%APPDATA%\SoftAudioSwitch`. Выбор выходов и их громкость сохраняются в реестре текущего пользователя. При переносе EXE на другой компьютер настройки остаются в старом профиле Windows.

Чтобы обновиться, выберите **Выход** в меню значка и замените EXE в той же папке. Если включили автозапуск и хотите перенести файл, выключите автозапуск перед переносом и снова включите его из нового расположения.
